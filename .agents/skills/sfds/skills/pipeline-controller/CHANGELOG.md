# CHANGELOG · pipeline-controller（仲裁版）

## 2.2.0-arb.1 — 2026-08-31（CASE-015/016）

从 zy-iot-ai 回灌（需求方 2026-08-30 确认：把「默认不激活」改为「开发类默认激活」）：

- **新增「默认激活与分层（强制）」**：开发类工作（重构/需求/bug 修复等 iterate 触发词）**默认登记 `T-xxx` 进流水线**，不再默认内联跑；唯一例外=用户显式声明「一次性/直接改/不用管线」。**分层**：pipeline-controller=外壳（队列/写锁/后台执行/零阻塞/恢复/过程留痕），iterate=内容引擎（级联计划）。
- **新增「过程留痕（process journal，强制）」**：`PIPELINE.md` 管「做什么+做到哪」，`.pipeline/journal/T-xxx.journal.md`（git 跟踪）管「怎么做+为什么」（需求原话/取舍得分/确认与仲裁理由/子代理事件时间线/中间产物路径）；崩溃/session 丢失后两者同读精确续跑。
- **新增模板** `templates/JOURNAL.md`；首次使用/文件布局/跨会话持久化同步 journal 化。
- description/whenToUse 更新（开发类默认进流水线）；lineage.reclaim 追加 2.2.0 条目。
- 与 iterate v1.1.0-arb.1「默认执行载体」+规则 #15 联动（两技能分层叠加）。
